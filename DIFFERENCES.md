# Differences from vanilla

- Adds a SHINY ODDS selector under START > OPTIONS > EXTRAS: DEFAULT (vanilla 1/8192), 1/4096, 1/2048, 1/1024, 1/512, 1/256, 1/128, 1/64, 1/32, or 100%. The default is DEFAULT (no change).
- Any non-default rate rolls a Pokemon's shiny status once (cached from then on) instead of using the vanilla personality/OT formula, including Pokemon already in the save the first time they're displayed after enabling the mod.
